# 👋 Hi, I'm Vaibhav Pandey

I'm a developer who likes working close to the metal: Linux systems, embedded hardware, signal processing and ML that actually runs on tiny devices. I'm also building up my Java backend and cybersecurity skills.

🌐 **Portfolio & blog:** [vpandey.codes](https://vpandey.codes)

## 🔭 What I'm Working On

- 🎧 **EchoGuard**: audio ML for embedded hardware, using adaptive filtering (NLMS), STFT features, a causal CNN, and INT8-quantized TensorFlow Lite models on ESP32
- ☕ Learning **Java backend development**: Spring Boot, Maven/Gradle, JPA/Hibernate, PostgreSQL
- 🔐 Studying **cybersecurity & networking**: Cisco Networking Academy, Kali Linux, pentesting fundamentals
